# Notes: Formulation & Implementation

This document describes the model math in `src/models/` and aligns the training pipelines so model differences are explicit.

## 1. Notation

- $B$: batch size
- $T\_{\mathrm{obs}}$: full trajectory length before partitioning
- $L$: context/window length used in each batch sample ($L \le T\_{\mathrm{obs}}$)
- $T\_{\mathrm{pred}}$: prediction horizon length
- $d_x$: observation dimension
- $d_z$: latent dimension
- $\sigma\_x^2$: fixed observation variance hyperparameter

Batch tensors:

- $x \in \mathbb{R}^{B \times L \times d\_x}$
- $m\_x \in \{0,1\}^{B \times L \times d\_x}$: observation-availability mask
- $t\_x \in \mathbb{R}^{L}$ (or $\mathbb{R}^{B \times L}$ with identical rows when required)

## 2. Discrete Latent SSM (`DiscreteSSM`)

Code:

- `src/models/discrete.py`
- `src/models/modules/latent_discrete.py`

### 2.1 Data Generating Process

$$
p\_\theta(z\_{1:L}, x\_{1:L}\mid t\_{1:L})
= p(z\_1)\prod\_{t=1}^{L-1} p\_\theta(z\_{t+1}\mid z\_t,\Delta t)
\prod\_{t=1}^{L} p\_\theta(x\_t\mid z\_t).
$$

### 2.2 Encode: Inference Model

Posterior encoder:

$$
q\_\phi(z\_t\mid x\_{1:L}, m\_{1:L}, t\_{1:L})
=\mathcal N\left(\mu\_t^q,\mathrm{diag}(\sigma\_t^{2,q})\right),
$$

with outputs
$\mu^q,\sigma^{2,q} \in \mathbb{R}^{B \times L \times d\_z}$.

Parameterization summary:

- value path: MLP projector on observations
- mask path: 1D-conv + linear projector on masks
- temporal encoder: bidirectional GRU on fused features with $\Delta t$
- posterior heads: forward/backward mean-scale heads with Gaussian merge

### 2.3 Decode: Latent Transition + Observation Decode

One-step latent transition:

$$
z\_{t+1}^{+} \sim \mathcal N\left(\mu\_t^p, \mathrm{diag}(\sigma\_t^{p,2})\right),
\qquad
\mu\_t^p = f\_\theta^\mu(z\_t,\Delta t),
\quad
\sigma\_t^{p,2} = (f\_\theta^\sigma(z\_t,\Delta t))^2.
$$

Here, both transition branches use the same transition input.
When `diag` is used, both $f\_\theta^\mu$ and $f\_\theta^\sigma$ are MLPs on that shared input.
When `const` is used, only $f\_\theta^\mu$ uses the transition network input and $\sigma\_t^{p,2}$ comes from a single learned scalar.

Observation decode:

$$
x\_{t+1}^{+} \sim \mathcal N\left(g\_\theta(z\_{t+1}^{+}),\mathrm{diag}(\sigma\_x^2)\right).
$$

Parameterization summary:

- latent projection network $r\_\theta$: MLP
- transition heads on $[r\_\theta(z\_t), \Delta t]$: mean MLP + scale branch (`const` scalar or `diag` MLP)
- observation decoder: `GaussianObsDecoder` (MLP mean head + fixed $x\_{\sigma2}$)

### 2.4 Training Pipeline (plus-one style)

1. Encode posterior path:
   $(\mu\_t^q, \sigma\_t^{2,q}) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$.

2. Build transition anchors $\bar z\_{1:L}$:
   - `mc_samples == 0`: $\bar z\_t = \mu\_t^q$.
   - `mc_samples >= 1`: sample and average $\bar z\_t=\frac{1}{S}\sum\_{s=1}^S z\_t^{(s)}$, $z\_t^{(s)}\sim q\_\phi$.

3. Compute one-step transition parameters on $\bar z\_{1:L-1}$:
   $(\mu\_t^p,\sigma\_t^{p,2}) = \mathrm{Transition}\_\theta(\bar z\_t,\Delta t)$.

4. Decode the mean transition path (no transition sampling in reconstruction):
   $x\_{2:L}^{+} = g\_\theta(\mu\_{1:L-1}^p)$.

5. Optimize reconstruction on targets/mask $(x_{2:L}, m_{2:L})$ and KL on latent states.

### 2.5 Objective

$$
\mathcal L\_{\mathrm{disc}} = \mathcal L\_{\mathrm{rec}}(x, x^{+}) + \beta\,\sum\_{t=1}^{L-1}\mathrm{KL}\left(q\_\phi(z\_{t+1}\mid x\_{1:L})\,\|\,p\_\theta(z\_{t+1}\mid z\_t,\Delta t)\right).
$$

- Reconstruction uses shifted targets $x_{2:L}$ (plus-one objective).
- Target mask is the shifted observation mask $m_{2:L}$.
- Reconstruction reduction is entry-weighted global reduction over selected entries (`mean` or `sum`).

## 3. Latent Neural ODE (`ODESSM`)

Code:

- `src/models/ode.py`
- `src/models/modules/latent_ode.py`

### 3.1 Data Generating Process

$$
\frac{dz(t)}{dt}=f\_\theta(t,z(t)),\qquad
p\_\theta(x\_i\mid z(t\_i))=\mathcal N\left(\mu^x\_i,\mathrm{diag}(\sigma\_x^2)\right).
$$

### 3.2 Encode: Inference Model

$$
q\_\phi(z\_0\mid x\_{1:L},t\_{1:L},m\_{1:L})
=\mathcal N(\mu\_0^q,\mathrm{diag}(\sigma\_0^{2,q})),
$$

Inference outputs a posterior over the initial latent state $z_0$.

Parameterization summary:

- sequence input: concatenated observation, mask, and $\Delta t$
- temporal encoder: single-direction GRU (`enc_direction`)
- projection block + output heads: projector, linear mean head, and diagonal-std head

### 3.3 Decode: Latent Transition + Observation Decode

Continuous-time latent transition:

$$
\frac{dz}{dt}=f\_\theta(t,z).
$$

Given $z_0$ and a time grid $\{t_i\}$, latent states are generated by ODE integration:

$$
z(t\_i)=\mathrm{ODESolve}(z\_0, f\_\theta, t\_i).
$$

**Key property**: Given initial state $z\_0$, the latent trajectory $z(t)$ is _fully deterministic_ via ODE integration. There is no stochasticity in the transition dynamics, to contrast with SDE which has $dW\_t$ noise at each step, and Discrete SSM which has stochastic transitions $p_\theta(z\_{t+1}\mid z\_t)$.

Observation decode:

$$
x\_i\mid z(t\_i) \sim \mathcal N\left(g\_\theta(z(t\_i)),\mathrm{diag}(\sigma\_x^2)\right),
$$

Parameterization summary:

- latent vector field $f\_\theta$: MLP
- ODE solver: `ODESolve`
- observation decoder: `GaussianObsDecoder`

### 3.4 Training Pipeline

1. Encode posterior over initial state:
   $(\mu\_0^q, \sigma\_0^q) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$.

2. Build initial latent states:
   - `mc_samples == 0`: $z\_0=\mu\_0^q$.
   - `mc_samples >= 1`: sample $z\_0^{(s)}\sim\mathcal N(\mu\_0^q,\mathrm{diag}(\sigma\_0^{2,q}))$ and keep $S$ trajectories.

3. Solve ODE and decode:
   $z^{(s)}(t)=\mathrm{ODESolve}(z\_0^{(s)}, t\_{\mathrm{target}})$, then $x\_{\mathrm{pred}}^{(s)}=g\_\theta(z^{(s)}(t))$.

4. Optimize reconstruction + $\beta\_{\mathrm{KL}}\mathrm{KL}(q\_\phi(z\_0|x)\| \mathcal N(0,I))$, with sample aggregation controlled by `loss_mode` (`elbo` or `iwae`).
   * reconstruction strategy can be `reconstruct` ($t\_{\mathrm{target}}=x\_{\mathrm{tps}}$) or `predict` ($t\_{\mathrm{target}}=y\_{\mathrm{tps}}$), with the target values aligned with $t\_{\mathrm{target}}$'s. 

### 3.5 Objective

$$
\mathcal L\_{\mathrm{ode}}
=\mathcal L\_{\mathrm{rec}} + \beta\_{\mathrm{KL}}\,\mathrm{KL}\left(q\_\phi(z\_0\mid x)\|\mathcal N(0,I)\right).
$$

This keeps the same high-level structure (reconstruction + KL).  

`loss_mode` controls only how sample-wise reconstruction terms are aggregated:

**`elbo`**:

$$
\mathcal L\_{\mathrm{rec}} = \frac{1}{S}\sum\_{s=1}^S \mathcal L\_{\mathrm{rec}}^{(s)}.
$$

**`iwae`**:

$$
\mathcal L\_{\mathrm{ode}} = -\log\sum\_{s=1}^{S}
\exp\left(\log p\_\theta(x\_{\mathrm{target}}\mid z^{(s)}(\cdot)) - \beta\_{\mathrm{KL}}\,\mathrm{KL}\right).
$$

Per-sample reconstruction term:

$$
\mathcal L\_{\mathrm{rec}}^{(s)}
= -\log \mathcal{N}\left(x\_{\mathrm{target}}\,;\, x\_{\mathrm{pred}}, \sigma\_x^2 I\right),
$$

where $x\_{\mathrm{target}}$ are the target observations on the reconstruction grid and $x\_{\mathrm{pred}} = g\_\theta(z^{(s)}(t))$ are the decoded predictions from the ODE-integrated latent trajectory.

KL term regularizes the initial latent state distribution toward a standard Gaussian prior.

## 4. Latent Neural SDE (`SDESSM`)

Code:

- `src/models/sde.py`
- `src/models/modules/latent_sde.py`

### 4.1 Data Generating Process

$$
dz\_t=f\_\theta^\mu(t,z\_t)\,dt + f\_\theta^\sigma(t,z\_t)\,dW\_t,
\qquad
p\_\theta(x\_i\mid z\_i)=\mathcal N\left(\mu^x\_i,\mathrm{diag}(\sigma\_x^2)\right).
$$

### 4.2 Encode: Inference Model

Posterior path encoder:

$$
q\_\phi(z\_t\mid x\_{1:L},t\_{1:L},m\_{1:L})
= \mathcal N\big(\mu\_t^q, \Sigma\_t^q\big),
$$

with parameterization by `z_sigma_type` (`const`, `diag`, `full`).

Covariance construction from posterior parameter $\sigma\_t^q$:

- `const`: $\Sigma\_t^q = \sigma\_{\mathrm{const}}^2 I$ (shared across time and dimension)
- `diag`: $\Sigma\_t^q = \mathrm{diag}((\sigma\_t^q)^2)$ (encoder emits positive per-dimension scales)
- `full`: $\Sigma\_t^q = L\_t^q (L\_t^q)^\top$, where $L\_t^q$ is the lower-triangular factor built from packed $\sigma\_t^q$

Parameterization summary:

- sequence input: concatenated $x\_t$, $m\_t$, and $\Delta t$
- temporal encoder: single-direction GRU (`enc_direction`)
- projection block + output heads: projector, mean head, and scale head (`const`/`diag`/`full`)

### 4.3 Decode: Latent Transition + Observation Decode

One-step SDE transition via Euler-Maruyama (EM) style in solver:

$$
z_{t+1}^{+}
= z\_t + \mu\_t^{p,\mathrm{inc}} + \left(\Sigma\_t^{p,\mathrm{inc}}\right)^{1/2}\varepsilon\_t,
\qquad
\varepsilon\_t \sim \mathcal N(0,I).
$$

with
$\mu\_t^{p,\mathrm{inc}} := f\_\theta^\mu(t,z\_t)\Delta t$
and
$\Sigma\_t^{p,\mathrm{inc}}:=\Sigma\_t^p\Delta t$, 
where
$\Sigma\_t^p=f\_\theta^\sigma(t,z\_t)f\_\theta^\sigma(t,z\_t)^\top$. 

Observation decode:

$$
x_{t+1}^{+}
\sim \mathcal N\left(g\_\theta(z\_{t+1}^{+}),\mathrm{diag}(\sigma\_x^2)\right).
$$

Parameterization summary:

- drift network $f\_\theta^\mu$: MLP
- diffusion network $f\_\theta^\sigma$: scale branch with `const`/`diag`/`full` modes
- transition integrator: Euler-Maruyama `SDESolver`
- observation decoder: `GaussianObsDecoder`

### 4.4 Training Pipeline (plus-one style)

1. Encode posterior path:
   $(\mu\_t^q, \sigma\_t^q) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$.

2. Build transition anchors:
   - `mc_samples == 0`: anchors are posterior means $\mu\_{1:L}^q$.
   - `mc_samples >= 1`: anchors are sampled posterior path (MC-averaged).

3. One-step Euler-Maruyama transition on anchors:
   $z\_{t+1}^{+}=\mathrm{EMStep}\_\theta(\mathrm{anchor}\_t, t, \Delta t)$.

4. Decode plus-one latents and compute reconstruction on targets/mask $(x_{2:L}, m_{2:L})$.

5. Optimize reconstruction + KL, where `kl_mode` (`mc`/`exact`/`vae`) selects the KL branch.

### 4.5 Objective

$$
\mathcal L\_{\mathrm{sde}}
= \mathcal L\_{\mathrm{rec}} + \beta\_{\mathrm{KL}}\,\mathcal L\_{\mathrm{KL}}.
$$

For the reconstruction term, current implementation supports both `MSE` and `NLL` (via toggle `loss_type`); KL term is selected by `kl_mode`, with each mode illustrated below. 

**`mc` (sampled-increment matching)**: sample latent path $z\_t \sim q\_\phi(z\_t\mid x\_{1:L},t\_{1:L},m\_{1:L})$, form increments $\Delta z\_t = z\_{t+1}-z\_t$, and match them against SDE-implied increment statistics:

$$
\mathcal L\_{\mathrm{mc}}=\sum\_t\left[\widetilde{\mathcal L}\_{\mathrm{mc}}\left(\Delta z\_t;\,f\_\theta^\mu(t,z\_t)\Delta t,\,
\Sigma\_t^p \Delta t\right)\right].
$$

In code, this is implemented via Gaussian-NLL-style building blocks (diag/full branches).

**`exact` (closed-form Gaussian KL on increment distributions)**: define

$$
q\_{\mathrm{inc},t}=\mathcal N\left(\mu\_{t+1}^q-\mu\_t^q,\,\Sigma\_{t+1}^q+\Sigma\_t^q\right),
$$

and

$$
p\_{\mathrm{inc},t}=\mathcal N\left(\mu\_{t}^{p,\mathrm{inc}},\,\Sigma\_t^{p,\mathrm{inc}}\right).
$$

Here, $\mu\_{t}^{p,\mathrm{inc}} = f\_\theta^\mu(t,z\_t^{\mathrm{in}})\Delta t$ is the model increment mean used by the exact-KL branch.
Also, $\Sigma\_t^{p,\mathrm{inc}}$ is the model increment covariance used by exact-KL, where $\Sigma\_t^{p,\mathrm{inc}}=\Sigma\_t^p\Delta t$ and $\Sigma\_t^p$ is parameterized from diffusion-network output
$f\_\theta^\sigma(t,z\_t^{\mathrm{in}})$:
- diag branch: $f\_\theta^\sigma$ outputs per-dimension positive scales $\sigma\_t^p$ and $\Sigma\_t^p=\mathrm{diag}((\sigma\_t^p)^2)$
- const branch: $f\_\theta^\sigma$ outputs a single positive scalar $\sigma\_{\mathrm{const}}$ and $\Sigma\_t^p=\sigma\_{\mathrm{const}}^2 I$
- full branch: $f\_\theta^\sigma$ outputs a lower-triangular factor $L\_t^p$ and $\Sigma\_t^p=L\_t^p(L\_t^p)^\top$

$z\_t^{\mathrm{in}}=z\_t$ for `mc`-style net inputs and
$z\_t^{\mathrm{in}}=\mu\_t^q$ for `exact` / `vae` net inputs.
Then

$$
\mathcal L\_{\mathrm{exact}}=\sum\_t \mathrm{KL}\left(q\_{\mathrm{inc},t}\,\|\,p\_{\mathrm{inc},t}\right).
$$

**`vae` (standard VAE on latent posterior KL)**:

$$
\mathcal L\_{\mathrm{vae}}=\sum\_t \mathrm{KL}\left(\mathcal N(\mu\_t^q, \mathrm{diag}(\sigma\_t^{2,q}))\;\|\;\mathcal N(0,I)\right).
$$

In this branch, posterior covariance is diagonal.

## 5. Model Comparison

All three models support irregularly spaced timestamps. The main difference is in parameterization:
- **Discrete** conditions one-step transitions on adjacent time gaps $\Delta t$.
- **ODE** evolves latent states with continuous-time dynamics on the provided evaluation grid.
- **SDE** uses drift/diffusion parameterization with Euler-Maruyama updates driven by adjacent $\Delta t$.

Primary mathematical differences lie in where stochasticity enters and how latent transitions are parameterized.

### 5.1 Posterior Encoder

| Model | Posterior | Outputs |
|-------|-----------|---------|
| **Discrete** | Per-step: $q\_\phi(z\_t\mid x\_{1:L},m\_{1:L},t\_{1:L})=\mathcal{N}(\mu\_t^q, \mathrm{diag}(\sigma\_t^{2,q}))$ | $\mu^q, \sigma^{2,q} \in \mathbb{R}^{B \times L \times d\_z}$ |
| **ODE** | Initial state: $q\_\phi(z\_0\mid x\_{1:L})=\mathcal{N}(\mu\_0^q, \mathrm{diag}(\sigma\_0^{2,q}))$ | $\mu\_0^q, \sigma\_0^{2,q} \in \mathbb{R}^{B \times d\_z}$ |
| **SDE** | Per-step: $q\_\phi(z\_t\mid x\_{1:L},m\_{1:L},t\_{1:L})=\mathcal{N}(\mu\_t^q, \Sigma\_t^q)$ | $\mu^q \in \mathbb{R}^{B \times L \times d\_z}$, $\Sigma^q$ (const/diag/full) |

**Notation**: $\mu^q$, $\sigma^q$ (or $\Sigma^q$) denote posterior parameters from the encoder:
- **Discrete**: $(\mu\_t^q, \sigma\_t^q) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$ for each timestep $t$.
- **ODE**: $(\mu\_0^q, \sigma\_0^q) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$ for initial state only.
- **SDE**: $(\mu\_t^q, \sigma\_t^q) = \mathrm{Encoder}\_\phi(x\_{1:L}, m\_{1:L}, t\_{1:L})$ for each timestep $t$.

### 5.2 Latent Transition Dynamics

Observation times may be irregularly spaced; $\Delta t$ denotes the adjacent time gap.

| Model | Transition | Stochasticity |
|-------|------------|---------------|
| **Discrete** | $z\_{t+1}^+ \sim p\_\theta(z\_{t+1}\mid z\_t, \Delta t) = \mathcal{N}(\mu\_t^p, \mathrm{diag}(\sigma\_t^{2,p}))$ | Per-step stochastic transition sampling |
| **ODE** | $\frac{dz}{dt} = f\_\theta(t,z)$, solved via $z(t\_i)=\mathrm{ODESolve}(z\_0, f\_\theta, t\_i)$ | **Deterministic** given $z\_0$ |
| **SDE** | $z\_{t+1}^+ = z\_t + \mu\_t^{p,\mathrm{inc}} + (\Sigma\_t^{p,\mathrm{inc}})^{1/2}\varepsilon\_t$, where $\varepsilon\_t \sim \mathcal N(0,I)$ | Per-step Gaussian transition noise |

**Notation**: $\mu^p$, $\sigma^p$ (or $\Sigma^p$) denote prior/model transition parameters:
- **Discrete**: $\mu\_t^p = f\_\theta^\mu(z\_t, \Delta t)$ (transition mean), $\sigma\_t^{2,p} = (f\_\theta^\sigma(z\_t, \Delta t))^2$ (transition variance).
- **ODE**: Deterministic vector field $f\_\theta(t, z)$; no stochastic parameters.
- **SDE**: $\mu\_t^{p,\mathrm{inc}} = f\_\theta^\mu(t, z\_t)\Delta t$ (drift increment), and $\Sigma\_t^{p,\mathrm{inc}}=\Sigma\_t^p\Delta t$ with $\Sigma\_t^p = f\_\theta^\sigma(t, z\_t) f\_\theta^\sigma(t, z\_t)^\top$ (per-unit-time diffusion covariance).

### 5.3 Core Modeling Differences: Side by Side Comparison

**Discrete SSM**:
- Dynamics: discrete-time latent transitions on adjacent steps.
- Inference scope: posterior inferred at every step $t=1,\dots,L$.
- Transition rule: $z\_{t+1}\sim p\_\theta(z\_{t+1}\mid z\_t,\Delta t)=\mathcal N(\mu\_t^p,\mathrm{diag}(\sigma\_t^{2,p}))$ with $(\mu\_t^p,\sigma\_t^{2,p})$ from $f\_\theta^\mu,f\_\theta^\sigma$.
- Stochasticity source: per-step transition sampling from the latent Gaussian transition law.
- Latent regularization: $\sum\_{t=1}^{L-1} \mathrm{KL}(q(z\_{t+1}\mid x) \| p(z\_{t+1}\mid z\_t))$.

**Latent ODE**:
- Dynamics: continuous-time deterministic latent flow with vector field $f\_\theta(t,z)$.
- Inference scope: posterior inferred only for initial state $z_0$.
- Transition rule: latent path is generated by numerical integration, $z(t\_i)=\mathrm{ODESolve}(z\_0,f\_\theta,t\_i)$.
- Stochasticity source: only initial-state sampling ($z\_0\sim q$); transitions are deterministic given $z\_0$.
- Latent regularization: $\mathrm{KL}(q(z\_0\mid x) \| \mathcal{N}(0,I))$.

**Latent SDE**:
- Dynamics: continuous-time stochastic latent flow with drift $f\_\theta^\mu$ and diffusion $f\_\theta^\sigma$.
- Inference scope: posterior inferred at every step $t=1,\dots,L$ (as in Discrete).
- Transition rule: Euler-Maruyama plus-one update, $z\_{t+1}^{+}=z\_t+\mu\_t^{p,\mathrm{inc}}+(\Sigma\_t^{p,\mathrm{inc}})^{1/2}\varepsilon\_t$, $\varepsilon\_t\sim\mathcal N(0,I)$.
- Stochasticity source: per-step transition noise through $\varepsilon\_t$ and increment covariance $\Sigma\_t^{p,\mathrm{inc}}$.
- Latent regularization: `kl_mode` in {`mc`, `exact`, `vae`} (increment-based matching/KL or VAE-style prior KL).

### 5.4 Practical Implications

To compare complexity cleanly, separate two axes:

1. **Objective-side complexity** (reconstruction + KL terms).
2. **Dynamics-integration complexity** (how latent transitions are numerically generated).

**Inference-side cost (encoder):**
- All three use recurrent encoders with similar sequence-length scaling.
- **ODE** infers only $z_0$; **Discrete/SDE** infer per-step latents $z_{1:L}$.

**Objective-side complexity:**

| Model | Transition Parameterization | Latent Regularization | Objective-Side Cost |
|-------|-----------------------------|-----------------------|---------------------|
| **Discrete** | mean + std branch per step | Step-wise Gaussian KL, $\sum\_{t=1}^{L-1}\mathrm{KL}(q(z\_{t+1}\mid x)\,\|\,p(z\_{t+1}\mid z\_t))$ | Moderate |
| **ODE** | deterministic vector field | KL on $z\_0$ only, $\mathrm{KL}(q(z\_0\mid x)\,\|\,\mathcal{N}(0,I))$ | Simplest objective |
| **SDE** | drift + diffusion branch per step | `kl_mode` in {`mc`,`exact`,`vae`} | Moderate to complex (depends on KL mode / covariance type) |

**Dynamics-integration complexity:**
- **Discrete**: fixed one-step transition per interval; cost scales roughly linearly with number of intervals.
- **SDE (Euler-Maruyama)**: fixed one-step transition per interval; also linear in intervals, with extra per-step diffusion work.
- **ODE**: integration cost depends on solver work, especially number of function evaluations (**NFE**) in adaptive ODE solvers; runtime is not determined by timestamp count alone.

So:
- **ODE has the simplest objective**, but can still be expensive in wall-clock time when NFE is high.
- **Discrete and SDE are closest in fixed-grid rollout structure**.
- **SDE adds extra cost** mainly when:
1. using increment-based KL (`mc`/`exact`) instead of a simple latent-state KL;
2. using `z_sigma_type='full'`, which introduces matrix-heavy operations (solve/inverse/log-determinant style terms) in loss computation.

**When Discrete and SDE are most comparable:**
- both use per-step latent inference and two transition branches;
- SDE with `kl_mode='vae'` and constant/diagonal diffusion is the closest objective profile to Discrete.

**Forecasting/ensemble cost:**
- For all models, sampling multiple forecast trajectories scales approximately linearly with the number of trajectories.
- ODE ensembles sample multiple initial states; SDE/Discrete ensembles sample stochastic transitions along rollout.

**Irregular timestamps:**
- **ODE** handles irregular times via continuous-time integration on the provided grid.
- **Discrete/SDE** consume irregularity through per-interval $\Delta t$ in fixed-step updates.

## 6. Implementation Notes

### 6.1 Shared Training Skeleton

Across all three models, training follows the same high-level sequence:

1. Infer posterior latent distribution from observed context.
2. Build latent transition anchors (posterior mean or posterior samples).
3. Apply model-specific latent transition.
4. Decode latent states to observation space.
5. Optimize reconstruction and latent regularization terms.

Encoder note:
- ODE and SDE share a common sequence encoder implementation (`RNNEncoder` in `src/models/modules/common.py`), while Discrete uses its own bidirectional encoder design.
- In ODE, $z_0$ posterior moments are read from the first encoder-step output; SDE uses per-step posterior outputs across the full context window.

### 6.2 Loss Handling Across Models

All three are reconstruction-plus-regularization objectives, but with different latent regularizers.

**Discrete**

$$
\mathcal L\_{\mathrm{disc}} = \mathcal L\_{\mathrm{rec}} + \beta\_{\mathrm{KL}}\,\sum\_{t=1}^{L-1}\mathrm{KL}\left(q(z\_{t+1}\mid x)\,\|\,p(z\_{t+1}\mid z\_t,\Delta t)\right).
$$

**ODE**

$$
\mathcal L\_{\mathrm{ode}} = \mathcal L\_{\mathrm{rec}} + \beta\_{\mathrm{KL}}\,\mathrm{KL}\left(q(z\_0\mid x)\,\|\,\mathcal N(0,I)\right).
$$

`loss_mode='elbo'` averages per-sample reconstruction terms; `loss_mode='iwae'` uses log-mean-exp aggregation over MC samples.

**SDE**

$$
\mathcal L\_{\mathrm{sde}} = \mathcal L\_{\mathrm{rec}} + \beta\_{\mathrm{KL}}\,\mathcal L\_{\mathrm{KL}},
$$

where `kl_mode` chooses $\mathcal L\_{\mathrm{KL}} \in \{\mathcal L\_{\mathrm{mc}},\mathcal L\_{\mathrm{exact}},\mathcal L\_{\mathrm{vae}}\}$.

### 6.3 MC-Sample Semantics

- `mc_samples = 0`: deterministic anchor from posterior mean.
- `mc_samples >= 1`: posterior sampling branch is enabled.
- **Discrete/SDE reconstruction**: sampled latent paths are averaged to a single anchor trajectory before plus-one transition decoding.
- **ODE reconstruction**: sampled initial states can remain as separate trajectories (sample axis retained), enabling `loss_mode='iwae'`.

### 6.4 Reconstruction Reduction and Masking

- Reconstruction uses entry-weighted global reduction (`mean` or `sum`) after masking selected entries.
- Masking is handled consistently through observation availability masks in encoder inputs and reconstruction loss selection.

### 6.5 Unified Interface and Fidelity

- This implementation provides a unified interface for `DiscreteSSM`, `ODESSM`, and `SDESSM`, so practitioners can switch model families with minimal pipeline changes.
- The implementation is designed to stay faithful to the mathematical formulations in the original latent neural ODE and SDE repositories ([YuliaRubanova/latent_ode](https://github.com/YuliaRubanova/latent_ode), [alluly/ident-latent-sde](https://github.com/alluly/ident-latent-sde)).
- Any intentional differences are documented explicitly in [DIFFERENCES.md](./DIFFERENCES.md).
